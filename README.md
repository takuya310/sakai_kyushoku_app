大阪府堺市の小学校給食献立が見れるアプリです。

堺市の小学校給食情報オープンデータは以下のURLから取得できます。
https://data.bodik.jp/dataset/271403_elementary_school_lunch

PDFデータは、堺市のホームページに掲載されています。
https://www.city.sakai.lg.jp/kosodate/kyoiku/gakko/school_lunch/concept/food-menu.html

github pagesで稼働する構成で構築しています。
データはcsv形式で保持しているため、オープンデータのExcelまたはホームページに掲載されているPDFを元にcsv化し、登録してください。
